# FastDeploy-UIE-Windows

FastDeploy-UIE-Windows 是一个命令行工具，基于百度飞桨 FastDeploy，在 Windows 平台上运行 UIE 模型，用于抽取和识别 UIE 结果。

## 功能特性
- 支持在 Windows 平台运行百度飞桨的 UIE 模型。
- 提供高效的命令行操作方式。
- 输出结构化的识别结果，便于后续处理。

## 安装

### 环境要求
- Windows 10 或更高版本
- CMake 3.15 或更高版本
- Visual Studio 2019 或更高版本
